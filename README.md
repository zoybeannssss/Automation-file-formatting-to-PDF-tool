# Automation-file-formatting-to-PDF-tool
Konversi word, excel, ppt secara offline dan tanpa upload!

BENEFIT
1. konversi file word, excel, ppt (beta), foto menjadi PDF secara offline, cepat
2. cocok untuk kerja yang butuh konversi file jadi PDF secara batch
3. cocok untuk file konfidensial yang tidak boleh diupload ke cloud namun ingin kerja cepat

NOTES!
1. wajib download python (Disarankan versi terbaru)
2. wajib download libary: pywin32, pyautogui
3. untuk pengonversian PPT masih tahap beta dan masih perlu perbaikan
4. fungsi konversi excel, word, foto sudah stabil
5. untuk excel wajib mengatur ukuran dengan page break view, jika tidak maka format file anda kepotong
